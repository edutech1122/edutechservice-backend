# Pinned exactly (not >=): the msbte_result_analysis gazette parser is
# coordinate/regex-based against pdfplumber's and PyMuPDF's text-extraction
# output, which does shift between releases in ways that can silently break
# that parsing (a newer release changed enough that a real, previously-good
# 613-page gazette started failing with "No result-sheet pages could be
# read from this PDF" in production while the exact same file parsed fine
# in testing against these versions). An unpinned >= let Render's build
# resolve a version we never actually tested. Bump these deliberately, and
# re-verify against a real gazette, rather than letting them float.
